Walk-forward on the volatile basket (h20): **ties the baselines** (mean +0.0006 Brier; bootstrap best); h60 unmeasurable. Signal **redundant** with bootstrap + `vix_*`/vol features.
  - **LSTM sequence model (`lstm_seq`, `forecasting/sequence.py` + `sequence_tune.py`, optional `[sequence]`/torch extra).** Pooled LSTM over feature sequences → softmax over horizon-scaled buckets; leakage-safe, deterministic. Investigated **exhaustively** (2026-06-03): heavy 3–4 layer + LayerNorm **architecture search**, **LR sweep** (3e-5→1e-3), full 114-ticker universe, train/val/test date split, **114-ticker held-out validation**, and a **calibration sweep** (temperature · isotonic · `CalibratedClassifierCV(cv=3)` isotonic & sigmoid). Result: extracts a **real but redundant** vol signal (pooled big-move AUC +0.02–0.04 over historical) yet **loses Brier/ECE on ~75% of tickers** (win-rate 25%/27% at h20/h30); **no calibration method helps** (raw already well-calibrated at pooled level; val→test shift degrades every fitted calibrator). Architecture/LR response surfaces are **flat** → no extractable signal beyond the redundant one. **Transformer ruled out** (more capacity, same inputs). torch segfaults alongside lightgbm on macOS → tests env-gated (`RUN_SEQUENCE_TESTS=1`); default gate + CI never load torch.

Next levers, in order of EV: **(a) Task 9 — GARCH** — a principled conditional-volatility model as a Monte-Carlo/baseline-tier upgrade (different *mechanism* — forward vol mean-reversion + leverage + fat tails — not just more capacity; per-ticker, no pooling/overlap problem; likely a small *real* tail/VaR win); **(b) Task 10 — point-in-time news** — genuinely new information (deferred to last).
