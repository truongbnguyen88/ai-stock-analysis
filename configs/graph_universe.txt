# WHY A SUBSET, NOT `--all`: graph extraction is the only PAID step in A5 (one claude-sonnet call per
# filing-section over the long 10-K Item 1 / Item 1A). Extracting the full ~110-name training universe
# costs ~$40-60 and is wasted for entity-anchored SEC QA — GraphRAG is query-local (you traverse from
# the question's ticker, §16.5), so you only need each queried ticker's own out-edges plus its named
# neighbors' INGESTED filings (already present). This list = NVDA + its supplier/peer complex, which
# covers the A4 bridging benchmark and every realistic "who supplies / competes with / is exposed to"
# question. Grow only when a new ticker is actually queried structurally.
#
